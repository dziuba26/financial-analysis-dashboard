# Objective

Build a professional portfolio project demonstrating finance, data analysis, and technology skills.

The finished project should help Anthony obtain Financial Analyst or Wealth Management internships.

---

# MVP

Build an interactive dashboard analyzing one public company.

Current target:

Apple Inc.

Reason:

Apple has relatively simple financial statements and is widely understood by recruiters.

# Constraints

Keep the project small.

It should be finishable in approximately two weeks of part-time work.

Avoid unnecessary features.

Avoid cloud services.

Avoid APIs unless they meaningfully simplify the project.

Avoid authentication.

Avoid Docker.

Avoid deployment.

Focus on demonstrating analysis rather than software engineering.

---

# Success Criteria

A recruiter should be able to:

Understand the project in under two minutes.

See clear financial analysis.

See SQL experience.

See Python experience.

See Excel experience.

Anthony should be able to explain every major component without reading code.
