# Financial Analysis Dashboard

A portfolio project combining Excel, SQL, Python, SQLite, pandas, Plotly, and Streamlit to analyze a public company's financial performance.

The current MVP focuses on **Apple Inc.** because its financial statements are widely understood and easier to explain in an internship interview.

## Project Goal

Build a professional, finance-first dashboard that shows:

- core financial results
- clean data flow
- SQL experience
- Python analysis
- Excel reporting
- clear analyst observations

The purpose of this project is not to over-engineer software. The purpose is to use practical technology to support better financial analysis.

## Planned Deliverables

- Excel workbook
- Python project
- SQLite database
- Streamlit dashboard
- SQL query examples
- dashboard screenshots
- professional GitHub repository

## Dashboard Scope

The dashboard will include:

- company and fiscal year selector
- revenue
- net income
- EPS
- ROE
- revenue trend
- net income trend
- EPS trend
- ROE trend
- basic analyst observations

## Data Flow

```text
Public financial data
-> CSV
-> pandas
-> SQLite
-> SQL queries
-> Streamlit dashboard
-> Excel export
```

Every displayed value should be traceable back to its source. No financial values should be fabricated.

## Project Principles

- keep the project small and interview-ready
- prioritize readability and maintainability
- separate raw data from processed data
- separate calculations from visualization
- avoid unnecessary cloud services, authentication, Docker, or deployment
- focus on financial analysis over software complexity
