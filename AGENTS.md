## Teaching style

Before writing code:

- explain the problem
- explain the approach
- identify what Anthony should learn

After writing code:

- summarize every file changed
- explain the most important code
- explain why the code exists
- explain the finance concept involved if applicable
- provide commands to test the changes

Keep explanations concise.
